# User guides

One page per role, for staff on their first day:

- [Cashier](cashier.md): the counter, receipts, customers on credit, closing the drawer
- [Pharmacist](pharmacist.md): stock entry, expiry, ordering, returns and reports
- [Pharmacy Admin](pharmacy-admin.md): setup, staff and roles, expenses, reports and your data

The keyboard shortcut card for the counter and stock entry prints from the app: press **?** on any screen, then **Print a shortcut card**. Server setup, backups, restore and recovery are in the [Developer runbook](../runbook.md).
